# Cakify brand mark

`cakify-mark.svg` is the source artwork for the application mark.

- The three conversation lines form an abstract `C` and suggest a streaming response.
- The dark ink conveys control and reliability; the muted blue is reserved for active states.
- The rounded square follows Windows app-icon geometry without adding gloss, gradients, or decorative detail.
- Keep at least 16% clear space around the inner mark. Do not recolor individual bars independently.

The GPUI shell recreates the same geometry with native primitives so the sidebar mark adds no image-loading cost.
